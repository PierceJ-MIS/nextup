# NextUp

My app helps gamers decide which games to purchase next by using data on past games played to determine what new games a certain individual would enjoy.

> A course project for **MIST 4600: Computer Programming in Business** at the University of Georgia's Terry College of Business (Fall 2026).

## Problem
My target market is all gamers, in need of a new exciting game to play, that are still scrolling on the recommended page. Finding a new game that you will actually enjoy is nearly impossible, but with the help of my app, you will be finding new games in no time.

## What it does
My app answers three questions:
1. **Sub-question 1:** Which games has this gamer enjoyed in the past? ( Based on hours played)
2. **Sub-question 2:** What genre of games does this gamer typically play? ( Based on game library) 
3. **Sub-question 3:** What are the most popular games out right now in their niche?

## Data
The [Steam Games Dataset](https://www.kaggle.com/datasets/artermiloff/steam-games-dataset) on Kaggle, collected in March 2025. The dataset is shared under the MIT License by its creator, artermiloff. This repo uses `steam_games.csv`, a smaller file made for the course: the 1,000 games with the most reviews.
